# 테니스 동호회 주간 대진표 자동화

매주 일요일 20:00~22:00, 귀뚜라미 클린 테니스 코트 K·L 두 면 / 8명 / 3타임 대진표를
참석자 명단만 주면 자동으로 짜주는 도구입니다.

## 모바일 웹사이트

`docs/`에는 GitHub Pages에서 바로 배포할 수 있는 정적 웹사이트가 있습니다.

- 회원을 눌러 8명을 선택하거나 새 참가자를 입력
- 기존 규칙과 히스토리 가중치를 적용한 후보 3개 생성
- 후보별 벌점과 주요 지표 비교
- 같은 타임 안에서 드래그하거나 두 선수를 차례로 눌러 교체 후 즉시 재평가
- 대진 확정, 복사·공유, 지난 참석자 재사용, JSON 백업
- 신규 회원 추가, 회원 비활성화·재활성화
- 잘못된 대진 보관·복원 및 보관 기록의 후보 계산 제외
- Firebase 연결 전에는 브라우저 로컬 저장, 연결 후에는 운영자 2명이 같은 기록 사용

로컬에서 확인하려면 저장소 루트에서 아래처럼 실행한 뒤
`http://localhost:4173`을 엽니다.

```bash
python3 -m http.server 4173 --directory docs
```

Firebase 연결과 GitHub Pages 운영 준비는 [`docs/SETUP.md`](docs/SETUP.md)를
참고하세요. 후보 생성은 브라우저 안의 규칙 기반 코드가 담당하므로 LLM이나
별도 서버가 필요하지 않습니다.

## 주간 사용법 (Claude에게)

> **"이번 주 참석자: 김제우 김동원 이채윤 진혜주 조재윤 신명수 김예은 조영혜"**

이렇게 8명만 알려주시면 대진표 후보 3개를 텍스트로 보여드립니다.
확인 후 **"1번으로 확정"** 이라고 하시면 히스토리에 저장됩니다.

**직접 고쳐서 주셔도 됩니다.** 수정한 대진표를 그대로 붙여넣으시면 후보와 같은 기준으로
채점해서, 어느 항목이 좋아지고 나빠지는지 비교해드립니다. 판단은 회장님이 하시면 됩니다.

인원은 **항상 8명**입니다. 자리가 비면 게스트로 채우시고, 성별·실력만 같이
알려주세요 → `"게스트 박OO 남자 B급"`
게스트는 매번 다른 사람으로 처리하므로 **이름을 기록하실 필요 없습니다.**

## 직접 실행할 때 (터미널)

```bash
# 대진표 후보 3개 생성
python3 scripts/matchup.py generate 김제우 김동원 이채윤 진혜주 조재윤 신명수 김예은 조영혜

# 날짜 지정 / 게스트 포함
python3 scripts/matchup.py generate --date 2026-08-16 \
    --guest "박게스트:남:B" 김제우 김동원 이채윤 진혜주 조재윤 신명수 김예은 박게스트

# 마음에 안 들면 다른 조합 뽑기
python3 scripts/matchup.py generate --seed 7 <이름 8개>

# 직접 짠 대진표 채점 (후보와 비교할 때)
python3 scripts/matchup.py score my-plan.txt <이름 8개>

# 확정 → data/history.md 에 저장
python3 scripts/matchup.py save --pick 1

# 후보가 아닌 직접 짠 대진표를 확정
python3 scripts/matchup.py save --from my-plan.txt --date 2026-08-16

# 회원 명단 / 이력 확인
python3 scripts/matchup.py members
python3 scripts/matchup.py history
```

주요 옵션

| 옵션 | 설명 |
|------|------|
| `--date YYYY-MM-DD` | 대진 날짜. 기본값은 히스토리에 없는 다음 일요일 |
| `--guest 이름:성별:레벨` | 게스트 추가 (여러 번 사용 가능) |
| `--top N` | 후보 개수 (기본 3) |
| `--seg-slot 1\|2\|3` | 실력 분리 타임 위치 (기본 2타임) |
| `--must-play 이름:남복\|여복\|혼복` | 한 타임은 그 사람이 해당 경기를 하도록 보장 |
| `--separate 이름A,이름B[@타임]` | 두 사람을 다른 코트에 배치. `@3` 이면 3타임에 고정 |
| `--never 이름:N남M녀` | 그 사람이 해당 성별 구성 코트에 못 들어가게 (모든 타임) |
| `--seed N` | 같은 명단으로 다른 조합을 보고 싶을 때 |
| `--explain` | 벌점이 어느 항목에서 나왔는지 분해해서 표시 |

## 파일 구조

```
data/members.csv    회원 명단 (이름·성별·레벨)  ← 신입/탈퇴/승급 시 여기만 고치면 됩니다
data/levels.csv     레벨 → 점수 환산표
data/history.md     확정된 대진표 기록 ← 파트너 중복 회피에 사용
docs/rules.md       대진 규칙과 가중치 설명
scripts/matchup.py  생성기 본체
```

## 출력 예시

```
## 2026-08-16 코트운영

20:00-20:50 (몸풀기 포함)
K코트: 김제우 김예은 vs 이채윤 조재윤
L코트: 진혜주 신명수 vs 김동원 조영혜

20:50-21:25
K코트: 김제우 조재윤 vs 김동원 신명수
L코트: 이채윤 김예은 vs 진혜주 조영혜

21:25-22:00
K코트: 조재윤 신명수 vs 이채윤 진혜주
L코트: 김제우 조영혜 vs 김동원 김예은
```

팀은 `vs`로 구분하고, **점수가 높은 팀을 왼쪽**에 둡니다.

대진표와 함께 아래 같은 균형 분석도 같이 나옵니다.

```
2타임 20:50-21:25 ← 실력 분리 타임
  K코트: 김제우+조재윤(8) vs 김동원+신명수(7)  | 차이 1 | 남복
  L코트: 이채윤+김예은(4) vs 진혜주+조영혜(3)  | 차이 1 | 여복
[파트너 중복] 없음 (총 12쌍 모두 다름)
```

## 회원 정보 수정

`data/members.csv`를 편집하면 됩니다.

```csv
이름,성별,레벨,비고
홍길동,남,B+,
```

성별은 `남`/`여`, 레벨은 `A+ A B+ B B- C+ C C-` 중 하나입니다.

## 규칙 요약

1. **최소 한 타임은 잘하는 사람끼리 / 못하는 사람끼리** — 유일한 필수 조건 (기본 2타임)
2. **한 코트 안 두 팀의 실력 균형** — 벌점에서 가장 큰 몫
3. 같은 날 **같은 파트너 반복 금지** (3타임 12팀 전부 다르게)
4. 같은 상대와 **3타임 내내 붙지 않기**
5. 되도록 **혼복·남복·여복** (2남2녀 코트는 혼복)
6. 최근 몇 주간 같이 친 사람·붙었던 상대는 되도록 피하기

자세한 가중치와 판정 기준은 [`docs/rules.md`](docs/rules.md) 참고.
