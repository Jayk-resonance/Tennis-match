# 주간 대진표 생성

## 1. 참석자 확인

사용자가 준 이름을 `data/members.csv`와 대조합니다.

- 인원은 **항상 8명**입니다. 8명이 아니면 진행하지 말고, 빈 자리를 게스트로
  채울 것인지 물어보세요.
- **명단에 없는 이름**은 게스트입니다. **성별과 실력(레벨)을 먼저 물어보세요.**
  추정하지 마세요. 확인 후 `--guest "이름:남:B"` 로 넘깁니다.
- 게스트는 **매번 다른 사람**으로 처리됩니다(이력 조회 제외). `여자게스트` 처럼
  같은 이름이 반복돼도 괜찮으니, 닉네임·실명을 기록하자고 제안하지 마세요.
- 게스트가 정회원이 되면 그때 `data/members.csv`에 추가할지 물어보세요.

## 2. 생성

```bash
python3 scripts/matchup.py generate --date YYYY-MM-DD <이름 8개> [--guest "이름:성별:레벨"]
```

`--date`를 생략하면 히스토리에 없는 다음 일요일이 자동 선택됩니다.

그날만의 요청은 **말로 맞춰주지 말고 옵션으로 하드 조건**을 거세요.

| 요청 예시 | 옵션 |
|-----------|------|
| "한 타임은 OO가 남복 치게 해줘" | `--must-play "OO:남복"` |
| "OO와 XX를 한 타임은 떼어줘" | `--separate "OO,XX"` |
| "OO는 여자 셋 사이에 넣지 마" | `--never "OO:1남3녀"` |

조건이 불가능하면 생성기가 오류로 알려줍니다. 조건을 하나씩 더해가며 벌점을 비교해
**각 조건이 얼마를 치르는지** 함께 알려주세요. 요청이 누적되면 이전 조건도 계속 유지합니다.

## 3. 사용자에게 보여주기

**후보 3개를 전부 대진표 본문까지 펼쳐서** 보여줍니다. 1번만 보여주고 나머지를
말로 요약하지 마세요. 그 위에 추천 하나를 고르고 이유를 답니다.

체크해서 같이 알려줄 것:
- 실력 분리 타임이 몇 타임인지
- 팀 점수 차가 1점 이상인 코트가 있으면 그 사실과 이유
- 파트너 중복 / 3타임 내내 같은 상대인 쌍
- 게스트가 있으면 어떤 실력으로 계산했는지

## 4. 사용자가 고친 안을 제시하면 (역제안)

**추측하지 말고 채점하세요.** 대진을 만드는 코드와 채점하는 코드가 같아서
총점이 후보와 직접 비교됩니다.

```bash
python3 scripts/matchup.py score <파일|-> <이름 8개> [--guest "이름:성별:레벨"]
```

- 어느 항목에서 좋아지고 나빠졌는지 **항목별 벌점 차이**로 설명합니다.
- 총점이 높다는 이유만으로 반대하지 마세요. 벌점은 현재 가중치의 반영일 뿐이고,
  코트에서의 체감은 사용자가 더 정확합니다. **비교해서 보여주고 선택은 사용자에게** 맡깁니다.
- 사용자 안이 필수 조건(실력 분리 타임)을 어기면 그건 분명히 알려줍니다.

## 5. 확정

승인 전에는 절대 save 하지 마세요. 승인되면:

```bash
python3 scripts/matchup.py save --pick 1                       # 생성 후보
python3 scripts/matchup.py save --from <파일> --date YYYY-MM-DD  # 사용자가 고친 안
```

그리고 `data/history.md`를 커밋·푸시합니다.

**확정을 번복하면** 해당 날짜 항목을 `data/history.md`에서 지운 뒤 다시 저장합니다.
같은 날짜가 이미 있으면 save가 오류로 막습니다. 손으로 옮겨 적지 말고,
후보를 다시 쓸 경우 히스토리에서 지운 다음 `generate`를 재실행해
같은 결과가 나오는지 확인하고 저장하세요(시드 없이 결정적으로 동작합니다).
