# 주간 대진표 생성

## 1. 참석자 확인

사용자가 준 이름을 `data/members.csv`와 대조합니다.

- **8명이 아니면** 진행 전에 반드시 물어보세요. (로테이션 규칙 미정)
- **명단에 없는 이름**은 게스트입니다. **성별과 실력(레벨)을 먼저 물어보세요.**
  추정하지 마세요. 확인 후 `--guest "이름:남:B"` 로 넘깁니다.
- 게스트가 다음에도 나온다면 `data/members.csv`에 추가할지 물어보세요.

## 2. 생성

```bash
python3 scripts/matchup.py generate --date YYYY-MM-DD <이름 8개> [--guest "이름:성별:레벨"]
```

`--date`를 생략하면 히스토리에 없는 다음 일요일이 자동 선택됩니다.

## 3. 사용자에게 보여주기

**후보 1번의 대진표 본문**을 그대로 보여주고, 그 아래 균형 분석을 요약합니다.
후보 2·3은 "다른 안도 있습니다" 정도로만 언급하고, 요청 시 펼칩니다.

체크해서 같이 알려줄 것:
- 실력 분리 타임이 몇 타임인지
- 팀 점수 차가 2점 이상인 코트가 있으면 그 사실과 이유
- 파트너 중복 여부
- 게스트가 있으면 어떤 실력으로 계산했는지

## 4. 확정

사용자가 승인하면:

```bash
python3 scripts/matchup.py save --pick 1
```

그리고 `data/history.md`를 커밋·푸시합니다.
승인 전에는 절대 save 하지 마세요.

수정 요청("A와 B는 붙여줘" 등)이 오면 `--seed` 값을 바꿔 다른 후보를 뽑거나,
후보 2·3을 제안하고, 그래도 안 맞으면 대진표를 직접 손보되
**표기 규칙(1·3번째가 한 팀, 2·4번째가 상대 팀)**을 지켜서 history.md에 기록하세요.
