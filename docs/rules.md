# 대진 규칙 명세

## 교류전 규칙 A

- 참석자는 TeSK 4명과 금테클 4명, 총 8명이다.
- B·C코트에서 20:00부터 30분씩 4타임을 진행한다.
- 1~3타임은 같은 클럽 선수 두 명이 한 팀이 되어 상대 클럽 팀과 경기한다.
- 4타임은 각 팀에 TeSK와 금테클 선수가 한 명씩 들어가는 혼합 파트너 경기다.
- 필수 조건을 만족하는 조합 중 팀 실력 차, 당일 파트너·상대 반복, 최근 교류전 이력, 성별 구성, B·C코트 배정 불균형의 벌점 합계가 낮은 후보를 우선한다.
- 교류전 이력은 정규전 벌점 계산과 분리한다.

## 0. 고정 조건

| 항목 | 값 |
|------|-----|
| 장소 | 귀뚜라미 클린 테니스 코트 (K코트 / L코트) |
| 요일·시간 | 매주 일요일 20:00 ~ 22:00 |
| 인원 | 코트당 4명 × 2코트 = **8명** |
| 타임 | 3타임 — `20:00-20:50 (몸풀기 포함)` / `20:50-21:25` / `21:25-22:00` |

## 1. 실력 점수 (`data/levels.csv`)

| 레벨 | A+ | A | B+ | B | B- | C+ | C | C- |
|------|----|----|----|----|----|----|----|----|
| 점수 | 6 | 5 | 4 | 3 | 2.5 | 2 | 1 | 0.5 |

## 2. 표기 규칙 ★

```
K코트: 김제우 진혜주 vs 김건희 이채윤
       └── 한 팀 ──┘    └── 상대 팀 ──┘
```

팀을 `vs`로 명시합니다. **점수가 높은 팀을 왼쪽**에 둡니다.

기존 표기(`김제우 김건희 진혜주 이채윤` — 1·3번째가 한 팀)도 파서가 계속 읽을 수 있어서,
히스토리에 옛 형식이 섞여 있어도 동작합니다. 다만 새로 저장되는 대진은 `vs` 형식입니다.

## 3. 규칙이 적용되는 방식

**순위표 같은 건 없습니다.** 규칙은 두 가지 서로 다른 방식으로 적용됩니다.

### 방식 A — 필수 조건 (통과 / 탈락)

> **최소 한 타임은 잘하는 사람끼리, 못하는 사람끼리**

이것 하나만 필수 조건입니다. 벌점이 아니라 **필터**입니다.
3타임 조합을 만들 때 이 조건을 만족하는 타임을 **반드시 하나 끼워 넣고** 시작하므로,
조건을 못 지킨 대진은 애초에 후보에 오르지 못합니다.

벌점으로 두지 않은 이유: 벌점이면 "밸런스가 아주 좋은 대신 분리 타임이 없는 대진"이
이길 수 있는데, 회장님이 "최소 한 타임은"이라고 못 박으신 규칙이라 타협 대상이 아닙니다.

### 방식 A-2 — 그 주에만 거는 추가 필수 조건

실력 분리 타임과 같은 하드 필터를 **그날만** 추가로 걸 수 있습니다.
못 지킨 대진은 후보에서 빠집니다. 전부 여러 번 지정할 수 있습니다.

| 옵션 | 뜻 | 적용 범위 |
|------|-----|-----------|
| `--must-play "이름:남복\|여복\|혼복"` | 그 사람이 해당 유형 경기를 함 | **한 타임 이상** |
| `--separate "이름A,이름B"` | 두 사람이 다른 코트에 있음 | **한 타임 이상** |
| `--separate "이름A,이름B@3"` | 두 사람이 다른 코트에 있음 | **지정한 그 타임** |
| `--never "이름:N남M녀"` | 그 사람이 그런 성별 구성 코트에 못 들어감 | **모든 타임** |

```bash
python3 scripts/matchup.py generate <이름 8개> \
    --must-play "남자게스트:남복" \
    --never "남자게스트:1남3녀" \
    --separate "김예은,조영혜"
```

앞의 둘은 "한 타임은 ~하게 해줘", `--never` 는 "절대 ~하지 않게 해줘" 입니다.
`--separate` 에 `@1`·`@2`·`@3` 을 붙이면 "**그 타임에** 떼어줘"가 되고,
여러 번 붙여 두 타임 이상을 지정할 수도 있습니다.
게스트가 혼자 여자 셋 사이에 끼는 상황을 막을 때 `--never "남자게스트:1남3녀"` 를 씁니다.

조건을 만족하는 배치가 아예 없으면(예: 여성이 3명인데 여복 요구) 오류로 알려줍니다.
가능하지만 비싼 조건이면 그냥 값을 치르고 짜므로, `--explain` 으로 얼마나 손해인지
확인한 뒤 판단하시면 됩니다.

### 방식 B — 벌점 합산 (나머지 전부)

나머지 규칙은 전부 벌점으로 바꿔서 **더한 뒤, 합이 가장 작은 대진**을 고릅니다.
서로 순위가 있는 게 아니라 **같이 저울에 올라가서 겨룹니다.**

| 규칙 | 벌점 단위 | 하루에 몇 번 적용되나 | 상수 |
|------|-----------|----------------------|------|
| 코트 내 팀 실력 균형 | 팀 점수 차 **1점당 10** | 코트 6개 | `W_BALANCE` |
| 일방적인 코트 | **1.5점 차 초과분** 1점당 **25** | 코트 6개 | `W_BAL_HEAVY` |
| 같은 날 파트너 중복 | 중복 **1회당 25** | 생길 때만 | `W_DUP_PARTNER` |
| 3타임 내내 같은 상대 | 해당 쌍당 **30** | 생길 때만 | `W_OPP_ALL3` |
| 혼복·남복·여복 어긋남 | 어긋난 코트당 **12** | 코트 6개 | `W_GENDER` |
| 최근 파트너 재조합 | 이력 가중치 × **5** | 팀 12개 | `W_HIST_PARTNER` |
| 최근 상대 재대결 | 이력 가중치 × **1.5** | 쌍 24개 | `W_HIST_OPPONENT` |
| 같은 날 상대 중복(2회) | 중복 **1회당 3** | 생길 때만 | `W_DUP_OPPONENT` |
| 코트 내 실력 편차 | 최고-최저 **1점당 0.5** | 코트 6개 | `W_SPREAD` |

### 3-0. 벌점 숫자를 비교할 때 주의할 점

**단위가 다르므로 숫자만 보고 세다/약하다를 판단하면 안 됩니다.**

- 실력 균형 `10`은 **1점 차당**입니다. 6개 코트에서 조금씩 쌓여 보통 **합계의 40% 안팎**을 차지합니다.
- 실력 균형만 선형으로 매기면 "1점 차 코트 두 개"와 "2점 차 코트 한 개"가 같은 값이 됩니다.
  실제로는 후자가 훨씬 나쁘므로 **1.5점 차를 넘는 초과분에 25를 더 물립니다**(`W_BAL_HEAVY`).
  이 항목이 없을 때 `6 vs 1.5` 같은 코트가 최적해로 뽑히는 일이 실제로 있었습니다.
- 파트너 중복 `25`는 **한 번 어길 때마다**입니다. 숫자는 크지만 12팀을 전부 다르게
  짜는 게 거의 항상 가능해서, 실제로는 **거의 항상 0**입니다. 사실상 필수 조건처럼 작동합니다.
- 상대 중복은 **2회와 3회를 다르게** 봅니다. 2회는 `3`으로 가볍게, 3타임 내내 붙는 건
  `30`으로 무겁게 막습니다. 회당 3점만 물렸더니 밸런스 0.5점 차이에도 밀려서
  같은 쌍이 3타임 내내 맞붙는 일이 생겼기 때문입니다.
- 상대 이력 `1.5`는 계수가 작아 보이지만 **하루 24번** 적용되어 체감이 큽니다.
  (같은 이유로 예전에 있던 '최근 같은 코트' 항목은 하루 36번 적용되며 합계의 39%를
  차지해 없앴습니다. 같은 코트 = 파트너 아니면 상대이므로 두 항목에 이미 포함됩니다.)

그래서 **"실제로 얼마나 세게 작용하는가"는 `계수 × 적용 횟수`로 봐야 합니다.**
`--explain` 옵션을 붙이면 그 대진의 벌점이 항목별로 얼마씩 나왔는지 비율까지 보여줍니다.

```
$ python3 scripts/matchup.py generate --explain <이름 8개>

[벌점 내역]  ※ '실력 분리 타임'은 벌점이 아니라 필수 조건 — 이미 통과
  코트 내 팀 실력 균형       40.0  (35.7%)   팀 점수 차 1점당 10  × 코트 6개
  최근 상대 재대결          29.0  (25.9%)   이력 가중치 × 1.5  × 쌍 24개
  최근 파트너 재조합         16.5  (14.7%)   이력 가중치 × 5  × 팀 12개
  혼복·남복·여복 어긋남       12.0  (10.7%)   어긋난 코트당 12  × 코트 6개
  코트 내 실력 편차          8.5  ( 7.6%)   최고-최저 1점당 0.5  × 코트 6개
  같은 날 상대 중복          6.0  ( 5.4%)   중복 1회당 3
  같은 날 파트너 중복         0.0  ( 0.0%)   중복 1회당 25
  3타임 내내 같은 상대        0.0  ( 0.0%)   해당 쌍당 30
  합계                112.0
```

가중치는 `scripts/matchup.py` 상단 `W_*` 상수에서 바로 조정할 수 있습니다.
"요즘 밸런스보다 다양성을 더 봤으면 좋겠다" 같은 요청이 있으면 이 숫자를 바꾸면 됩니다.

### 3-0-2. 직접 짠 대진을 채점하기 (역제안)

생성 후보가 마음에 안 들어 **직접 고친 안**을 쓰려는 경우, 감으로 판단하지 말고
`score`로 **후보와 같은 잣대**로 채점합니다. 대진을 만드는 코드와 채점하는 코드가
같은 함수(`local_penalty` + `global_penalty`)라서 총점이 직접 비교됩니다.

```bash
python3 scripts/matchup.py score my-plan.txt <이름 8개> [--guest "이름:성별:레벨"]
```

출력에는 균형 분석, 벌점 내역, **필수 조건 통과 여부**가 함께 나옵니다.
총점이 높다고 무조건 나쁜 안은 아닙니다. 벌점은 이 문서의 가중치를 반영한 값일 뿐이고,
코트에서의 체감은 회장님이 더 정확합니다. **어느 항목에서 얼마나 손해·이득인지 보여드리고
선택은 회장님이 하시는 것**이 이 명령의 목적입니다.

확정되면 후보가 아니어도 그대로 저장할 수 있습니다.

```bash
python3 scripts/matchup.py save --from my-plan.txt --date 2026-08-16
```

### 3-0-3. 게스트 처리

게스트는 **매번 다른 사람**으로 봅니다. 이름이 `여자게스트`로 같아도 지난주 게스트와
동일인으로 묶지 않습니다. 구현상 게스트가 낀 쌍은 이력 조회에서 제외됩니다
(`hist_key()`가 `None`을 반환).

닉네임이나 실명을 매번 기록할 필요가 없습니다. 실력·성별만 알려주면 됩니다.
게스트가 정회원이 되면 그때 `data/members.csv`에 추가합니다.

### 3-1. "실력 분리 타임" 판정

한 코트의 **최저 점수 ≥ 다른 코트의 최고 점수 − 0.5** 이면 분리된 타임으로 봅니다.
(`SEG_TOLERANCE = 0.5` — 0.5점 정도의 겹침은 허용. 예: B와 B-는 섞여도 분리로 인정)

기본적으로 **2타임**에 배치합니다. `--seg-slot 1|2|3` 으로 바꿀 수 있습니다.
과거 대진표를 보면 이 타임이 자연스럽게 남복/여복이 되는 경우가 많습니다.

### 3-2. 성별 조합 판정

| 조합 | 판정 | 벌점 |
|------|------|------|
| 남여 vs 남여 | 혼복 | 0 |
| 남남 vs 남남 | 남복 | 0 |
| 여여 vs 여여 | 여복 | 0 |
| 남남 vs 여여 | 남자 2명 vs 여자 2명 — 실력 차가 커서 안 씀 | 12 |
| 남남 vs 남여 / 여여 vs 남여 | 어긋남 | 12 |

이 벌점이 실제로 갈리는 건 **코트에 2남2녀가 있을 때**뿐입니다.
이때 가능한 3가지 팀 나누기 중 2개는 혼복, 1개는 `남남 vs 여여`인데,
벌점 12는 실력 차 1.2점에 해당하므로 웬만하면 혼복이 이깁니다.

3남1녀·1남3녀 코트는 어떻게 나눠도 어긋나므로 3가지 모두 같은 벌점을 받아
결과에 영향을 주지 않습니다. 4남·4녀 코트는 어떻게 나눠도 남복·여복입니다.

### 3-3. 이력 가중치

`data/history.md`의 최근 8회차를 회차당 **0.75배씩 감쇠**시켜 합산합니다.
(직전 회차 1.00 → 그 전 0.75 → 0.56 → 0.42 …)

### 3-4. K / L 코트 배정

같은 사람이 3타임 내내 한 코트에만 있지 않도록 K·L을 자동 배분하고,
동점이면 분리 타임의 상위권 코트를 K로 둡니다.

## 4. 인원은 항상 8명

기록된 4주(2026-07-12 ~ 08-09)를 전부 확인한 결과 **매주 정확히 8명**이었고,
3타임 내내 같은 8명이었습니다. 모자란 자리는 게스트로 채우셨습니다
(2026-08-02의 `남자게스트` / `여자게스트`).

그래서 생성기는 8명이 아니면 **오류로 막습니다.** 게스트는 실력·성별만 알려주면
`--guest "이름:성별:레벨"` 로 넣을 수 있습니다.

`python3 scripts/matchup.py history` 를 실행하면 회차별로 타임 수·인원·성별 구성·
파트너 중복을 점검해줍니다.

## 5. 의도된 예외 표기

규칙을 알고도 일부러 어긴 회차는 `data/history.md`의 날짜 줄 바로 아래에 적어둡니다.

```markdown
## 2026-08-09 코트운영
> 의도된 예외: 파트너 중복
```

점검이 **그 항목만** 눈감아 주고 `OK (의도된 예외 — ...)` 로 표시합니다.
쉼표로 여러 개를 적을 수 있고, **적지 않은 다른 문제는 그대로 잡힙니다.**

표시만 바뀔 뿐 **벌점 계산과 이력 가중치에는 영향이 없습니다.** 예외로 적어둬도
그 파트너 조합은 다음 주에 여전히 회피 대상입니다.
